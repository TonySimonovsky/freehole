# freehole

A tiny TypeScript browser game inspired by Hole.io: move a hole across the ground and let objects fall in to earn points.

Initial scope: a flat plane with only apples.

Future scope: full city scenes (buildings, cars) for the hole to consume.



// I want to create a browser game like Hole.io where there is a plane (ground) and various objects on it. You move the whole across the groudn and objects fall into that hole giving you points.
