# 3D Models

Place your .glb or .gltf model files in this directory.

## Recommended Sources:

1. **Poly Pizza** - https://poly.pizza (low-poly game assets)
2. **Sketchfab** - https://sketchfab.com (filter by downloadable, glTF format)
3. **Quaternius** - https://quaternius.com (free low-poly assets)

## Model Requirements:

- Format: .glb or .gltf
- Size: Small objects suitable for a Hole.io style game
- License: Ensure you have rights to use the model

## Naming Convention:

Use descriptive names like:
- `duck.glb`
- `car.glb`
- `box.glb`
- `pyramid.glb`
